## Cost and model rules

Use reusable artifacts and deterministic local checks first. For one bounded
main pass, choose Free in the actual host selector. If it fails an acceptance
check due to reasoning or implementation limits, checkpoint completed work and
continue only that slice in Power if needed. No unconditional paid review or
Max fallback. The skill cannot change the selector; actual mode is unknown
until the host confirms it. Free allowances have limits; hosting, storage and
third-party services do not become free.
