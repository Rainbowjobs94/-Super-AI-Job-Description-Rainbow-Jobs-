## Manual use

Select Free in the actual host model selector. Upload one inner source wrapper
ZIP or the revised Hab skills; choose one inactive workflow copy. Inspect source
and permissions, run applicable local tests and save the checkpoint before any
Power continuation. Chat Free allowance does not make storage/deployment/APIs
free; plan limits, concurrency and security holds still apply.

Source archives are owner-library reference snapshots, not automatically copied
into running project sandboxes. The queued project task must fetch permitted
pinned source or receive an explicitly approved private upload, then ingest via
the canonical Hab core, expose read-only/export views and review merge mappings.
No original source or earlier successful result is overwritten to save credits.
