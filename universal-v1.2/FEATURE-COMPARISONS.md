# Options, gains and what remains disabled

These choices add alternatives; they do not remove original modules or uploads.

| Choice | Gain | Still disabled or lost in that mode | Safe fallback |
| --- | --- | --- | --- |
| One-module copy/paste | Small context; works without native skill support | Automatic tool calls, persistent memory, background work | Owner executes reviewed instructions |
| Individual root-SKILL ZIP | Simple one-skill upload, selected scope | Other modules are not implicitly installed | Import another selected module later |
| Whole-tree/root-loader pack | Preserved core plus all 14 modules and relative resources | Native import is not universal; folders may be unsupported | Individual ZIP or Markdown |
| GitHub docs-to-wrapper | Can reuse a docs/code-only repo without root SKILL.md | Cannot override host upload rules, licenses or access denial | Owner reviews and uploads generated wrapper |
| n8n manual templates | Repeatable bounded local preparation | Providers, schedules, webhooks, execution and durable approval | Manual review of generated plan |
| Future reviewed provider API | Structured jobs/search/artifact retrieval | Until approved: credential use, private-data sharing and paid calls | Manual agent task packet |
| Agent collective plan | Parallel roles for genuinely independent work | No unchecked fan-out, shared-file contention or self-approval | Single coordinator |
| HF card/README research | Low-cost discovery before hardware commitments | Model inference, weight downloads, remote code and paid jobs | Paper comparison with explicit unknowns |
| Public wallet/vault config | Auditable chain/role/environment references | Signing keys, decryption secrets and real transactions | Unsigned human-reviewed requests |
| External encrypted keystore | Separates encrypted data from reviewed unlock mechanism | Encryption alone does not provide safe custody or release approval | Hardware/external/multisig signer |

## Preservation and live operation

Nothing here deletes an earlier source or replaces the existing Hab runtime.
An obsolete link or maintenance-only framework is retained with its status.
Skipping a provider integration preserves local cataloging, prompt preparation
and manual workflows; it bypasses setup/cost today, not safety or licensing.

No background scheduler is installed by a research skill. “Stay up to date”
requires a separately approved schedule, runtime and source policy. Review only
changed revisions; do not repeatedly send every archive to every model.

Signing, custody, mainnet deployments, pools/treasuries, token issuance,
trading/betting, tax deductions and legal/regulatory clearance remain outside
this addendum. Existing economics/simulator work is preserved and separate.
