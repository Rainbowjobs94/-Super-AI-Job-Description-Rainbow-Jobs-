# IA Guardian Hab v1.3: expanded workflow library

This additive edition has **15 skill modules**, a portable root loader,
**20 inactive n8n preparation workflows**, and six proposed JSON-backed file
formats with samples and a structure-only validator. Original inputs and all
older ZIPs remain preserved. It is not a full live deployment.

## What to use

- One simple task: paste the existing universal packet and select one module.
- A host accepting one skill: unzip the individual-module collection and upload
  one chosen module ZIP with SKILL.md at its root.
- Whole library: use the root-loader pack and preserve its relative directories.
- Workflow JSON: import one of 20 templates and manually test synthetic input
  in the actual target n8n instance. Local tests do not prove live compatibility.
- File records: use hab-workflow-library/formats and its structure-only Python
  validator. Validation does not grant authority or verify IP/value.

The preserved core's CLI examples require the actual Hab runtime in a project.
Provider directions are not provider connections. A third-party importer may
require host-specific setup; manual Markdown remains the fallback.
For Replit workspace-wide availability, import chosen modules through workspace
Knowledge → Skills; local files/draft commits do not automatically activate them.

## Domain coverage

GitHub/intake/sync, deployment, environment, individual/collective agents,
standard/deep research, IP security, provenance, copyright/license, trademark,
patent, jurisdiction/compliance, debugging, protocols, file formats, roles,
market analysis/trends, checkpoints and review queues.
Additional playbook branches cover backup/restore, incidents, dependency/SBOM
review, cross-project compatibility, accessibility/performance and public claims.

## What remains disabled

All workflow templates are manual/inactive/no-network. No providers, schedules,
webhooks, filings, deployments, financial actions, real role grants or private
research sharing are activated. Credentials/signing keys stay outside Git.
Unknown jurisdiction, licensing or financial semantics remain review holds.
No unlimited-runtime/credit/suspension guarantee is made.

Use the previous comparison guide for mode tradeoffs and WORKFLOW-MENU.md for
the expanded domain choices. Existing release-security and simulator tasks
remain separate; no source conflict or rights ambiguity is silently discarded.
